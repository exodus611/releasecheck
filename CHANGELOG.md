# Changelog

## 0.1.0 — 2026-09-25

First working version.

- one command, one verdict: `PASS` or `FAIL`; exit codes `0` / `1` / `2`
- checks: files, duplicates, archives (CRC, zip-slip, epub and docx structure),
  epub metadata, secrets (including text inside archives, values masked),
  placeholders, hashes, image sizes, PDF structure, links
- optional `--online` link check; offline by default
- `--json` and `--md` reports for machines and for pull requests
- GitHub Action (`action.yml`) — usable in another repository with one line
- demo folders generated by the repository itself: no network, no fixtures that
  contain real secrets
- 11 unit tests, standard library only

Every report ends with **what this does not prove**.
